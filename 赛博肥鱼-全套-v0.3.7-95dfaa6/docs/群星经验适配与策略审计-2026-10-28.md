# 群星经验适配与策略审计

大肥鱼当前这局需要先消化已有疆域、修复经济与殖民地，再选择有价值的扩张。0.3.5把经验落实到游戏控制器的战略复盘、扩张门槛、建筑候选核验和参谋判断中；不会用固定年份、星系数量或帝国规模500作为发展目标。

## 当前路线与资料适用范围

当前局为常规定居民主帝国。上次`inspect government`返回`auth_democratic`、`ethic_fanatic_egalitarian`和`ethic_xenophile`，是极端平等与亲外路线。消费品、舒适度和稳定度需要进入内政判断。

用户提供的《群星4.5定居帝国 Codex查漏补缺操作指南 v2》描述的实况实际是蜂巢路线，用于借鉴发展顺序和检查覆盖面；《群星教程重制版 经验总结 Codex版》发表于较早版本，用于借鉴资源、岗位和专精的因果关系。蜂巢岗位、旧版本数值、建国模板、最终胜利和危机打法不能据此宣称适用于当前局。

资料里的审计模板作为核对依据。本次工作按用户提出的“更加运筹帷幄”改进现有程序，不更改帝国、难度、DLC、存档或原有游戏速度。

## 日志证据

上次保存于星历2287.08.25的局势为13个殖民地、55个星系、帝国规模443；消费品每月-104.76、库存3303.28，食物每月-74.64、库存2344.35，均约能维持31个月；海军373/255，凝聚力净收入-6.91。矿物与合金库存充足不能抵消这些瓶颈。

同轮日志有258次扩张查询、10次建哨站尝试、109条建筑意图；98次建筑回执中95次`success:false`、3次成功。建筑错误集中于区域容量或专精不匹配。程序原来还把建筑`slot_index`限制在0～128，而该字段实际需要完整`zone_id`，真实候选包含`33554590`。这是一个可以由代码和日志共同复现的错误，不能把修复产能失败全部归因于AI不会规划。

控制器`src/native-game.mjs`的`validateOrder`已允许原生接口支持的完整非负特区ID范围；`buildingCandidateProblem`在下单前核对当前星球、完整特区ID、区划类型、容量和可建候选。它会拒绝猜测槽位和错误专精，原生引擎仍作最终合法性判断。这里不把历史95次失败全部归为同一个原因，也不声称修复后这些建筑已实际建好。

## 经验转成的决策规则

游戏循环仍及时运行，战略复盘由本机已有状态计算，不新增模型调用、不人为降低操作频率。每次观察附带短小的`strategy`：当前路线、阶段、最多3条优先项、扩张是否暂缓和恢复条件。

| 阶段 | 判断与行动 |
| --- | --- |
| 防务与事件 | 处理当前战争、中央事件和战争目标，核对战力与路线，普通扩张暂缓。 |
| 经济稳定 | 核心资源亏损且库存约只够12个月时，先保住生产与维护，普通扩张暂缓。 |
| 消化疆域 | 亏损余量约不超过36个月、同时出现多项核心赤字，或已知有人口殖民地舒适度、住房或稳定度不佳时，先查原因并修复。 |
| 选择扩张 | 核心经济数据完整且上述瓶颈改善后，重新评估接壤、可达、有资源或边境收益的目标。 |

12个月、36个月和影响力约一年净收入余量是当前程序采用的保守运营策略，不是教程或游戏硬规则。资源字段缺失不当成0或财政健康；常规消费品义务不会直接套到蜂巢或机械路线。少量有长储备的单项赤字不会永久禁止扩张。

殖民地详情保留专精、总督、大小、宜居度、特征、劳动力、产出和施工队列；不再遗漏原生接口已有的专精与劳动力摘要。复盘列出最多3个待轮查殖民地，优先有提示的星球；近期核实的有人口殖民地低稳定、负舒适度或缺住房会提高内政优先级。未殖民星球的默认0稳定度不当成叛乱风险。

扩张下单时再次读取当前资源和候选，防止绕过提示。普通哨站只接收当前合法、已调查、与己方接壤的目标；影响力不足计划余量时暂缓。殖民只接收当前可殖民、己方星系、已知宜居度非红色的目标。候选先过滤排序再截取8个，避免前面无效目标挤掉后面的有效目标。这里没有新设殖民地或版图数量上限。

当前原生哨站候选只有合法性，没有逐目标折扣后的详细报价；影响力余量检查并非完整建设预算模型。目标的要道价值、长期收益、黄色宜居维护与新增人口成本仍由模型结合详情判断，不能把`can_build`等同于“值得建”。

红色宜居边界按本机4.5游戏文件`common/defines/00_defines.txt`核对：`HABITABILITY_OPPOSITE_PLANET=0.40`，黄色边界为`0.70`。不照抄资料中未核实的黄色数值或“帝国规模不要超过500”。[官方4.5开发记录](https://store.steampowered.com/news/posts/?appids=281990&enddate=1788433221)还涉及殖民地规划文件、AI预算等调整，早期教程中的具体操作须以当前接口和游戏脚本为准。

## 两份资料逐项对应

下表“策略提示”表示已经进入固定职责与参谋提示，但不等同于确定性程序已自动完成该项规划。

| 经验 | 本次对应与覆盖程度 |
| --- | --- |
| 资源优先级 | 战略复盘优先危机和供给，固定提示保护三线科研、凝聚力、合金；不把科研置于生存之上。 |
| 食物消费品够用即可 | 策略提示避免过量投入，复盘用库存余量诊断赤字；尚无逐建筑的全局人口再分配优化器。 |
| 工业专精先于堆量 | 保留专精字段，建筑下单核验当前特区与候选；专精切换工具尚未接入。 |
| 消费品短缺分级修复 | 策略提示先查岗位和低成本修复，不盲改主力专精；当前仅执行工具已有合法建造。 |
| 科研单独规划 | 观察保留三线科研与产出，空闲项进入优先级；科研星球长期布局由模型判断。 |
| 稀有资源分级 | 原有状态提供微粒、水晶、气体等资源；路线需求的完整预测预算未实现。 |
| 帝国规模成本 | 复盘显示规模，扩张考虑机会成本；不设置500上限，未实现全局最优规模求解。 |
| 岗位填充先于加建筑 | 策略提示和劳动力详情已接入；不能把空岗位当现成产出。 |
| 宜居度过滤 | 下单与候选过滤均拦截未知或红色宜居；黄色保留给收益评估。 |
| 大小特征与专精 | 星球详情保留大小、最多8条特征和阻碍项、专精；未增加自动改专精操作。 |
| 规划与对口建筑 | 用真实特区ID核验当前可建候选；不假设所有星球使用同一模板。 |
| 稳定度与舒适度 | 已知有人口殖民地的低稳定、负舒适度或住房短缺触发内政优先级；路线相关幸福度和派系调节仍缺执行工具。 |
| 移民与降级延迟 | 未接入完整迁移、人口改派与降级时程模型，不能承诺人口瞬间到位。 |
| 自动托管 | 未接入托管开关和策略配置；不替用户擅自开启自动建设。 |
| 舰容与基地维护 | 原有海军容量与赤字扩军保护保留；完整基地升级、模块与维护规划仍缺工具。 |
| 贸易收集与保护 | 旧教程具体收集机制在4.5未逐项核验；当前市场结算读取真实`trade`字段，不据此冒充贸易路线治理已实现。 |
| 科研船科学家与避险 | 原有舰船任命、当前候选、可达路径和可见敌情保护保留。 |
| 弱势外交与同时发育 | 策略提示保留改善关系与补科研、防务并行，不能把关系改善当永久安全。 |

四集审计中的C-21路线识别、C-25扩张规划、C-26殖民地复查、C-27建造、C-30稳定度和C-33多线优先级已有上述部分落地；C-24传统与凝聚力、C-29领袖、C-32调度保留现有能力，不宣称完整最优策略。C-22蜂巢建国复现、C-23创建特质校验、C-28共同体投票、C-31巨构全链路不在当前执行工具覆盖内。C-34年份仅可作观察参考，不设硬指标；C-35列明的最终胜利、天灾终局、堕落帝国决战、机械飞升和游牧路线未验收。附件引用的v1 C-01至C-20没有完整条目，未编造其逐条通过结果。
