# 模型列表与厂商图标（Windows 0.3.3）

原模型栏使用原生 `datalist`，打开时会用当前输入值过滤，自动填入首个模型后常只剩一条候选。另一个容易混淆的点是角色仍绑定原服务商，只会显示原服务商的模型；拉取中转站列表并不会擅自改变角色绑定。

已替换为完整模型选择器：打开时搜索词始终为空、显示该服务商所有缓存模型；支持搜索、按厂商分组、手填模型ID、键盘上下选择/回车/退出、当前选中标记。按钮明确显示当前服务商和模型数量。先在角色的“服务商”里选择自己的中转站，再打开“模型”即可看全已拉取的22个模型。

Claude、Gemini、OpenAI、DeepSeek、Qwen、Kimi、Grok、Meta、Mistral使用本地SVG图标，未知系列显示通用AI标记。归属优先根据模型ID判断，不能把中转返回的 `owned_by=antigravity` 误识别成模型厂商。完整模型ID保留；不因品牌识别过滤模型。图标来源与许可见 `assets/model-logos/ASSET_NOTICE.md`、`licenses/lobe-icons-MIT.txt`。

验证：69个测试文件共665通过、2项既有跳过；5项界面测试通过，含以22个缓存ID验证全量展开、三类品牌图标加载、搜索、键盘、手填、服务商切换和保存后重开。类型、Windows安装包及打包程序烟测通过。日志保存在 `.local/model-picker-*.log`，选择器截图在 `.local/artifacts/model-picker-menu.png`。
