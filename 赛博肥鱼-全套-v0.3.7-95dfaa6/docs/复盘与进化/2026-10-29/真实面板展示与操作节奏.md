# 真实面板展示与操作节奏（0.3.9控制器补丁）

用户反馈：昨天直播的程序操作不像人类，观众看不明白；希望看到真实操作过程，面板停留约10秒再关闭。用户进一步确认：重点是看见操作过程，无法可靠实现的部分可以保留限制。

## 已落实

普通操作先打开真实面板并确认成功，约2秒后才执行正常游戏命令，从打开算起整体停留约10秒，再关闭回到游戏。同面板的连续操作各自展示，不再受旧的10秒重复开窗缓存合并。命令执行和回读所耗时间计入10秒，若本身已超过10秒就不额外等待。

| 操作 | 当前实际可见内容 |
| --- | --- |
| 选择科技 | 科研面板先出现，再发生选择变化 |
| 造船、编制、增援、升级、合并 | 舰队管理窗口；有舰队目标时先定位真实镜头 |
| 交易、传统与飞升、外交、领袖、议程 | 对应市场、传统、外交、领袖、政府真实面板 |
| 星球建设、首府升级、岗位 | 已确认己方星球的真实镜头；目前没有可靠的星球详情开窗接口 |
| 调查、建站、移动、殖民 | 对应科研船、工程船或殖民船的真实镜头；不能声称已打开目标星系建造菜单 |

这些变化由原有正常游戏命令直接更新真实界面。本次没有添加鼠标动画或逐按钮点击，因而不声称已经完全模拟人类鼠标操作。没有可靠目标时记录“展示不可用”，不拿无关画面冒充对应面板。仅定位镜头的记录使用`kind:camera`，真面板使用`kind:panel`。

中央事件和战争目标按原生实际窗口处理；紧急舰队调动、跟随、阵型与合并优先执行，不为了展示拖延防务。普通经济动作不会只因“正在战争中”就全部跳过展示。等待每500毫秒检查停止、画面、事件、战争及新敌情；遇到新情况立即中断并暂停，保留新弹窗。写入前及异步检查返回后再检查停止信号，取消不能穿透到后续指令。
