## v1.3 的 P0 调查可用版

现有桌面“大肥鱼 DSH”快捷方式及“打开大肥鱼DSH-Windows.bat”继续使用本机源码构建。若旧窗口仍在运行，先停止控制再退出，由用户手动重新打开入口。

1. 停止状态下，在“群星控制”页勾选“启用混合调查”。这只保存当前控制器目录的配置，不操作游戏。默认保持普通模式，不悄悄启用。
2. 用户手动打开群星、载入所需单人存档，再点“启动大肥鱼”。开关明确传到当前控制器及模型工具；大肥鱼保留科技、方向和事件决定，原生自动调查处理已委派科研船的例行调查。
3. “调查分工”展示已委派、正在调查和待核对数量；待命不会算正在调查，过期状态不当作活跃工作。
4. 点“停止并接管”。收到确认时表示游戏已暂停并收回调查；若显示尚未确认，先在游戏核对，不把程序退出当成收权成功。
5. 回到普通模式：先停止并接管，取消勾选，再启动。运行中禁止改模式，不用开关直接覆盖现有控制权。
