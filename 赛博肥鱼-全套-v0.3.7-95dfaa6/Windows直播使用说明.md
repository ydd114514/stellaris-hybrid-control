# 赛博肥鱼 Windows 版

适用于 Windows 10/11 64 位。此目录已适配 Windows，保留原有角色、AI 配音、点歌、独立舞台和本机弹幕输入桥。

## 打开

本机已配置好肥鱼茶话铺画面和 VB-CABLE。推荐双击 `启动直播预览-Windows.bat` 联动打开小店与伴侣，并重绑当前窗口编号；伴侣正在直播或录制时，此入口会停止重配。该联动入口使用本机已安装的 Node.js、PowerShell 7 和源码依赖。

- 直接双击 `启动小店-Windows.bat`，会使用 `release/win-unpacked/赛博肥鱼.exe`，无需安装 Node.js。
- 安装版位于 `release/CyberFish-0.3.7-Windows-x64-Setup.exe`，安装后从桌面快捷方式打开。
- 先用 `启动本地测试-Windows.bat` 免费排练。排练使用独立数据，默认不出声、不连接真实直播间。
- 关闭后台窗口后会收进系统托盘，右键托盘可退出；直播采集窗口请保持打开、不要最小化。

## 抖音直播伴侣的画面和声音

1. 打开「直播连接 → 打开专用采集窗口」。在窗口素材中勾选「兼容性：3D 游戏需要勾选」。在直播伴侣添加窗口素材，选择 **赛博肥鱼 · 抖音直播采集（9:16）**，竖屏等比铺满。舞台按 540×960 逻辑像素运行，本机伴侣实际输出为 720×1280、30 帧；实际窗口像素随 Windows 缩放变化。
2. 从 [VB-Audio 官方页面](https://vb-audio.com/Cable/) 下载并安装 VB-CABLE Windows 驱动。驱动安装需要系统管理员操作，按安装器提示重启。应用不会自动安装驱动或改变系统默认声卡。
3. 小店「直播连接」重新检测：运行模式选择「直播」，专用输出选择 **CABLE Input (VB-Audio Virtual Cable)**，保存。

   Windows 系统设备列表可能将同一个播放端点显示为「扬声器 (VB-Audio Virtual Cable)」；小店会识别这两种名称。不要选额外的 16 声道端点作为本次设置的替代。
4. 直播伴侣麦克风选择 **CABLE Output (VB-Audio Virtual Cable)**；关闭系统声音采集和重复音频监听。Input / Output 名称看似相反，这是虚拟线缆的发送端与接收端。
5. 需要自己听时，打开小店「本地监听」，选择耳机或扬声器。不要选 CABLE Input，避免回路。关闭监听不停止直播送音。

本机系统声音保持走原扬声器，只有小店的千问配音和歌曲进入专用声卡；说话时自动压低音乐。直播模式不支持系统朗读，请配置千问配音。声卡断开时停止送音，不会回落到默认扬声器。

## 茶话铺画面与服装

- 牌匾为「肥鱼茶话铺」，角色、营业台和聊天记录整体上移，左下方留给平台弹幕。
- 右下角有慢煮茶炉与茶话小签，每 90 秒换一个聊天话题；抽签动作可提前换签。播放音乐时，茶炉位置显示点歌牌，避免叠在一起。
- 「形象与动作 → 服装」可切换女仆裙、牛仔装、南瓜女巫、幽灵斗篷，以及原有斗篷和店员装。新增服装使用分层骨骼，服色按参考图保留。头饰佩戴落点已下调，并扩大渲染边界以防鞠躬时裁掉帽檐。

## AI、音乐和弹幕

- 在「设置」填写自己的 DeepSeek / 千问密钥，关闭试营业。真实服务的测试、配音和聊天会产生服务费用；自动回归为离线测试；用户授权的真实千问配音测试单独记账，见本机配置记录。Windows 使用系统安全存储加密密钥。
- QQ 音乐需要在点歌台重新扫码登录，也可导入有播放权限的本地歌曲。Mac 保存的加密凭据不能搬到 Windows 直接解密。
- 「直播连接 → A 后台事件」手填当前抖音直播房间号或直播间链接后连接。Windows 当前不自动查找直播伴侣日志中的房号。匿名接收能否持续收到评论、礼物取决于平台，需要开播后验证。
- 已有弹幕工具可使用本机 HTTP / WebSocket 输入桥，支持小店标准事件与 DouyinBarrageGrab 格式，参见 `docs/直播接入参考.md`。令牌只交给本机工具。
- 「B 直播助手画面备用」支持 Windows 内置 OCR：列出窗口、选择伴侣窗口、设置评论与礼物区域、核对裁图后开启。需简体中文 OCR 语言组件；点击「预热本机识别」可检查。应用不下载识别模型，不把画面传到云端。
- Windows 备用通道只对选定伴侣窗口使用 PrintWindow，本机内存中裁图。最小化、管理员权限不匹配或 GPU 窗口不支持捕获时会明确失败或报告空白，不切到桌面采集。可保持窗口恢复、核对预览；失败时继续使用后台事件或输入桥。
- Windows OCR 没有逐行置信度接口，内部使用固定保守权重并继续做多帧确认；不能把该权重理解成实际准确率。屏幕读取不能核验真实身份、礼物金额或收入。

## 数据、源码和验证

在本项目内运行时，数据位于 `.local/user-data`；本地测试位于 `.local/test-data`。安装到项目以外时，默认使用「文档/赛博肥鱼/.local」，也可通过 `CYBER_FISH_HOME` 指定自己的数据根目录。测试全部使用隔离目录，不读取真实密钥。

开发环境需要 Node.js 22.18+ 或 24+、pnpm 11.25.0：

```sh
pnpm install
pnpm check
pnpm build
pnpm test:electron
pnpm package:win
node scripts/smoke-electron.mjs --packaged
node scripts/smoke-windows-ocr.mjs --packaged
node scripts/smoke-windows-capture.mjs --packaged
```

网络受限时，安装 Electron 与打包可临时设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，不关闭证书或校验。
