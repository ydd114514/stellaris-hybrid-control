# 混合控制连续长测

本入口已完成离线验证，尚未运行30或60分钟实机测试。必须按计划先完成短测对照、确认实际改善，再运行30分钟；前五阶段通过后才运行60分钟。命令准备成功不算上述阶段验收。

开发命令使用`C:\Program Files\Git\bin\bash.exe`，工作目录`E:\肥鱼直播\stellaris-player`。用户禁止桌面控制，入口不模拟键鼠、读档或重启游戏。实际执行前须有合适、已暂停的单人非铁人测试会话，核对当前局、资源与可调查目标。对照用的初始档应保留，不能用其他世界替代同档结果。

## 准备与运行

默认仅生成配置，不启动DSH、不读取模型密钥、不产生付费请求：

```bash
node scripts/run-hybrid-live.mjs --long-run
CYBERFISH_PILOT_MINUTES=60 node scripts/run-hybrid-live.mjs --long-run
```

满足计划的前序条件后，分别运行独立连续试验：

```bash
CYBERFISH_PILOT_MINUTES=30 node scripts/run-hybrid-live.mjs --long-run --execute
CYBERFISH_PILOT_MINUTES=60 node scripts/run-hybrid-live.mjs --long-run --execute
```

长测强制hybrid模式，仅支持30或60分钟，模型请求默认上限200，可用`CYBERFISH_PILOT_REQUESTS`调低，不能超过200。预算耗尽、错误、人工停止或初始化超时都保留真实原因，不算完成整轮。每轮独立目录和控制器会话，正常经营保留既有战略、任务、预算及调查控制权规则；没有调查专用试验的经营动作限制，未通过的殖民地自动化仍没有写入口。禁止控制台和改资源；现有正常游戏机制继续使用。

短测`run-survey-benchmark.mjs`的十分钟入口及其范围保持原样。长测不是替代同档对照，不能将其结果与另一条件的人工局计算节省比例。

## 计时与证据

长测启动后先有90秒控制器启动期限；读到本轮原生检查点后，截止改为该控制器真实`ends`。外层启动、原生控制器启动、游戏实际运行与停止清理分别记录。连续控制器时长以原生`stop_requested`日志边界减检查点`started`计算，不用外层最终报告时间补足时长，不把清理宽限算进去。单一会话文件和会话ID必须一致，不能累计停止重启的多轮。

`long-run-evidence.json`核对规定时长、单一会话、hybrid模式、真实请求计数、完整停止写入边界、停止后零工作写入和最终暂停/收权。停止的原始退出码仍记录；截止取消模型传输可能使DSH报告错误，不能改写成正常退出码0。

`technicalDurationPassed`只表示这些技术条件通过；`acceptancePassed`不会因凑够时间自动变真。还须独立核对多任务同期推进、至少一次大肥鱼主动干预、关键事件与人工暂停、实际原生费用及队列对账、控制冲突、效率与观感。安全暂停属于同一控制器运行时长，但不属于游戏实际运行时长；暂停与不确定采样区间另列。自然开局与加速条件分别报告。

停止与恢复演练另行保存记录，不累计为60分钟连续时长。本机DSH入口交付、回退和既有战役回归仍需独立验收，不以本脚本配置生成成功代替。
